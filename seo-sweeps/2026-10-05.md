## Judgment calls — for Nick

### 1. GBP, cleaned up: calls are flat, but website clicks and direction requests show a real, smaller dip
This report originally flagged GBP calls/website clicks as down 26-28% off a 30-day pull
ending "today." That number was inflated by a reporting lag — the last 3 days of that window
(Oct 2-4) read exactly 0 across every metric because Windsor.ai's GBP Insights data hadn't
landed yet, not because traffic stopped. Nick's own JARVIS dashboard (client portal) showed
the same inflated decline (803/76/55/99 vs 968/97/88/146, -17% to -37%) for the identical
reason: its "current" window also silently includes those same 3 zero days while its
"previous" window is a fully-settled month, so it's comparing a complete period against an
incomplete one. The two tools' raw totals for the broken window match exactly (803/76/55/99
both ways), confirming it's one underlying data-freshness issue, not two separate bugs.

**The clean comparison** (two fully-settled 28-day windows, Sep 3-30 vs Aug 6-Sep 2, neither
touching the lag days):

| metric | Sep 3-30 | Aug 6-Sep 2 | change |
|---|---|---|---|
| Impressions | 897 | 964 | -7% |
| Call clicks | 90 | 91 | **flat** |
| Website clicks | 66 | 85 | **-22%** |
| Direction requests | 119 | 140 | **-15%** |

**Calls are not actually down** — the 26% figure in the original version of this report, and
the 22% in JARVIS, were both lag artifacts. But website clicks (-22%) and direction requests
(-15%) hold up as real, smaller movements even on the clean comparison. Proposed next step,
not yet done: check whether the `location_metadata_has_pending_edits: true` flag on the
listing (an edit awaiting Google's review) is a website-URL change that could explain softer
website clicks specifically. Otherwise this is small-sample GBP data (66-91 clicks/month) and
a 15-22% move is a handful of clicks — within normal week-to-week range for a business this
size, worth one more sweep to see if it's a trend before treating it as one.

**JARVIS dashboard has the same lag bug and will keep showing inflated declines until it's
fixed there too** — worth telling whoever maintains that dashboard to hold back the last
3-4 days of any "current" window the same way this routine's Windsor pull now does.
