### 2. Google Business is now soft on a clean read, for the second week running
On fully settled, like-for-like 28-day windows: calls −14%, website clicks −20%, directions −19%,
impressions −9%. The last five days of the window are all non-zero, so this is not the lag
artifact that was retracted on 10-05. The prior window includes a 15-call day on Sep 1, which
inflates its call total somewhat. Website clicks and directions were also the soft lines last
week, so this is now a pattern.
The most likely contributor that can actually be fixed is **review velocity: no new Google
review in 59 days**, after roughly one a month before that. Reviews drive map-pack ranking, and
the map pack is where city searches get answered (CLAUDE.md). Nothing in this repo changed the
listing.
Proposed (owner action, no code): ask every discharged patient for a review and text them
`firstrehabnpb.com/review`. Separately, check what the listing's pending edit is
(`has_pending_edits` was true last week).

### 3. Hand therapy page "dropped" to 25.3, but it's a query mix shift, not a loss
`/services/hand-therapy.html` page-level position went 18.2 → 20.1 → 25.3. Breaking it down by
query, the page now mostly ranks for "hand therapist" (147 impressions at 34.5), while the
symptom query "hand pain treatment west palm beach" moved to `/treatments/hand-wrist.html`
(42 impressions at 23.5). That is exactly the split PR #92 set up: service page for
practitioner intent, condition page for symptoms. The averaged position fell because the page
shed better-ranking symptom queries, not because any query got worse.
What does deserve watching: neither page is close to page one yet. "hand therapist" at 34.5 is
the biggest non-brand hand query and is still the depth target. No action this week.
